# Home Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A home page at `/` that shows where the day stands: now and next, today's plan with the picker, projects in motion, recent items, activity today.

**Architecture:** One server payload (`homePayload` in `src/lib/home.ts`) gathers what the Planner, containers, items and activity domains already compute; the page is a client shell over it that refreshes on the app's existing change events, reusing `PlanPane`'s rows and picker, the capacity line, and the task row.

**Tech Stack:** Next.js 16 App Router, React 19 (react-compiler lint: no synchronous setState in effect bodies), Tailwind 4 Carbon tokens, Vitest 5 jsdom.

**Spec:** `docs/superpowers/specs/2026-09-24-home-design.md`

## Global Constraints

- Carbon tokens only (`src/test/tokens.test.ts`); sentence case; `focus-ring` on links and buttons; no synchronous `setState` in effect bodies; tests never touch the network; empty states are one line each.
- Depends on the sessions plan having landed (`TaskDTO.blocks`, `POST /api/plan/place`, `f` on rows).
